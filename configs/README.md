# configs

Configuration files used by training, evaluation, and runtime threshold loading.

## Files

- `cost_matrix.yaml` — Cost settings used when comparing privacy leaks and over-redaction during threshold selection.
- `encoder.yaml` — Configuration for encoder training and related model settings.
- `generative.yaml` — Configuration shared by generative detector experiments.
- `qwen.yaml` — Qwen and LoRA training/inference settings.
- `thresholds.yaml` — Frozen per-entity confidence thresholds used by evaluation and runtime loading.

## Notes

Keep this guide short. Update it when files move, are added, or change responsibility.
