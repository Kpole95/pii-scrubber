# tests / unit

Fast unit tests grouped by runtime text logic, research code, and scripts.

## Folders

- `research/` — Research-code unit tests.
- `scripts/` — Script unit tests.
- `text/` — Text-processing unit tests.

## Files

- `__init__.py` — Unit tests for runtime, research, and script modules. Main defs/classes: No top-level defs or classes.
- `test_threshold_profiles.py` — Tests for frozen runtime threshold profiles. Main defs/classes: `_write`, `test_load_balanced_profile`, `test_load_strict_profile`, `test_unknown_mode_fails`, `test_invalid_threshold_fails`.
