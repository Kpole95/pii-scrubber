# research

Research-only code for data preparation, evaluation, training, and the reviewed OOD benchmark.

## Folders

- `data/` — Dataset loading and normalization.
- `eval/` — Evaluation and calibration.
- `labeled_ood/` — Reviewed OOD benchmark data.
- `train/` — Encoder and Qwen training code.

## Files

- `__init__.py` — Offline training and evaluation code; never imported by the runtime package. Main defs/classes: No top-level defs or classes.
